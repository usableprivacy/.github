# usableprivacy.com

> **Simple Privacy Solutions for Everyone.**

Our mission is to build simple, effective, and accessible privacy-enhancing technologies that protect everyday internet users without requiring advanced technical expertise.

---

## Projects

### 1. Usable Privacy DNS (`updns`)
A privacy-protecting public DNS resolver supporting **DNS over HTTPS (DoH)** and **DNS over TLS (DoT)** with integrated ad, tracker, and malware filtering.
* **Repository:** [`usableprivacy/updns`](https://github.com/usableprivacy/updns) 
* **Documentation:** [docs.usableprivacy.com/dns](https://docs.usableprivacy.com/dns) 
### 2. Usable Privacy Box
#### Configuration Utility (`config`)
The management and configuration tool powering the **Usable Privacy Box (`upribox`)**—a hardware-based home network solution designed to filter ads and trackers across all connected devices.
* **Repository:** [`usableprivacy/config`](https://github.com/usableprivacy/config)
